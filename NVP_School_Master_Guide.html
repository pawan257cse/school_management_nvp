3. Step-by-Step Deployment Roadmap (Render + Vercel)

Step 1: Render.com Par Backend Deploy Karna

  1. Render.com me New Web Service banayein aur GitHub repo connect karein.
  2. Build Command: npm install | Start Command: node backend/server.js
  3. Environment Variables tab me yeh 4 keys dalein:
    • NODE_ENV = production
    • MONGODB_URI = (Aapka MongoDB Atlas connection URL)
    • JWT_SECRET = nvp_school_super_secret_jwt_key_2026_change_this
    • ADMIN_RECOVERY_KEY = NVP-HEAD-RECOVERY-KEY-2026
  4. Deploy hone ke baad mila Backend URL copy karein (e.g. https://nvp-backend.onrender.com).

Step 2: Vercel.com Par Frontend Deploy Karna

  1. Vercel.com me Add New Project karein aur wahi GitHub repo select karein.
  2. Root Directory: frontend select karein.
  3. Framework Preset: Vite auto-select ho jayega.
  4. Environment Variables me yeh 1 key dalein:
    • VITE_API_URL = https://nvp-backend.onrender.com (Step 1 ka Render URL, bina aakhiri slash ke)
  5. Deploy karein! Aapki school website live ho jayegi.
